# ScrollBoard

forked from [qinshaoxuan/ScrollBoard.js](https://github.com/qinshaoxuan/ScrollBoard.js)

XCPC竞赛滚榜展示插件，基于JQuery、Bootstrap.

展示页面：[Demo](http://labs.ac1liu.com/ScrollBoard/)

按一次空格或回车（可自行指定）可进行一步，即更新一个队的一个未知结果.

**支持：** 开始滚动动画、逐队伍展示、当前选中题目高亮显示

**使用方法：** 参考`index.html`文件中的设置和`data/data.json`文件的格式

Demo采用了2025年ICPC EC Final竞赛的数据.
